# Contosole

App per monitorare un impianto fotovoltaico: energia prodotta e consumata,
incentivi GSE (Scambio sul Posto, Ritiro Dedicato, Conto Energia), bollette,
investimento e rientro.

Questo repository contiene **solo i pacchetti dell'app** da scaricare. Il codice
sorgente non è pubblico.

## Download

Le versioni sono nelle **[Releases](https://github.com/alconsoftware/contosole-releases/releases)**.
Per ogni versione trovi le note sulle novità e i file da scaricare:

| Sistema | File | Come si installa |
|---|---|---|
| Android | `Contosole-<versione>.apk` | apri il file sul telefono e consenti l'installazione da questa fonte |
| Windows | in arrivo | |

Ogni Release riporta anche l'impronta **SHA-256** di ogni file. Puoi usarla per
verificare che il file scaricato sia integro e non sia stato modificato.
